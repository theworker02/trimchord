# trimchord

Trim and reshape chord text streams with deterministic transforms.

**Site:** https://theworker02.github.io/trimchord/

## Install / run

```bash
git clone https://github.com/theworker02/trimchord.git
cd trimchord
node src/cli.js
node --test
```
